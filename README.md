# バトルトリニティ タイマー

ドラゴンクエストX「バトルトリニティ」用の残り時間タイマーです（非公式ファンツール）。

**▶ 使う: https://lepanda-tools.github.io/trinity-timer/**

## できること
- ボーナスジュエル・援軍玉・ジュエルラッシュの出現を、数秒前と発生時に音声とビープでお知らせ
- ゲーム画面を共有すると、残り時間の数字を読み取って自動スタート・自動同期（PC版向け、Chrome / Edge）
- 手動スタート（Space）、±1秒補正、残り時間を入力しての同期にも対応

## タイムライン（残り時間）
| 残り | イベント |
|---|---|
| 4:30 / 2:30 / 0:30 | ボーナスジュエル（中央） |
| 3:30 / 1:30 | ボーナスジュエル（外周） |
| 4:00 / 2:30 / 1:00 | 援軍玉 |
| 5:30〜0:50 の約35秒ごと | ジュエルラッシュ（目安・±5秒） |
